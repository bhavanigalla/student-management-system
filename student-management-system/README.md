# Student Management System

A portfolio Student Management System built using:

- HTML
- CSS
- Vanilla JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- REST API

## Current Stage

Stage 1: Project setup and basic Express server.

## Run

```bash
npm install
npm run dev
```

API health check:

`http://localhost:5000/api/health`
